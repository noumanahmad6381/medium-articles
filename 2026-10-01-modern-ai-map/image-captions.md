Alt text / suggested caption: A map of 17 AI terms grouped by design, action, deployment, information, learning, and oversight. All groups describe dimensions of the same system.

Alt text / suggested caption: Scalable AI: a service handles increasing request volumes while speed, cost, and reliability remain design constraints.

## 02-modular-ai.png

Alt text / suggested caption: Modular AI: input processing, a model, and output processing connect through interfaces; the model can be replaced.

## 03-agentic-ai.png

Alt text / suggested caption: Agentic AI: a goal leads to observation, action, and a feedback loop within permissions.

## 04-distributed-ai.png

Alt text / suggested caption: Distributed AI: a shared job is split among several workers and the results are combined.

## 05-decentralized-ai.png

Alt text / suggested caption: Decentralized AI: peer nodes exchange information without one central coordinator.

## 06-edge-ai.png

Alt text / suggested caption: Edge AI: device data is processed locally or nearby, with an optional cloud connection.

## 07-federated-ai.png

Alt text / suggested caption: Federated AI: three sites retain local data while sharing model updates with an aggregator.

## 08-multimodal-ai.png

Alt text / suggested caption: Multimodal AI: text, images, and audio feed a shared interpretation.

## 09-generative-ai.png

Alt text / suggested caption: Generative AI: records and an instruction lead to a newly generated draft report.

## 10-embodied-ai.png

Alt text / suggested caption: Embodied AI: a robot senses an environment, moves within it, and senses the result.

## 11-adaptive-ai.png

Alt text / suggested caption: Adaptive AI: changed conditions lead to an update, evaluation, and monitored deployment.

## 12-neuro-symbolic-ai.png

Alt text / suggested caption: Neuro-symbolic AI: learned patterns and explicit knowledge connect to a joint inference.

## 13-collaborative-ai.png

Alt text / suggested caption: Collaborative AI: a person and an AI exchange context, proposals, and corrections around a shared task.

## 14-explainable-ai.png

Alt text / suggested caption: Explainable AI: a recommendation is connected to inspectable evidence and a meaningful explanation.

## 15-trustworthy-ai.png

Alt text / suggested caption: Trustworthy AI: reliability, safety, security, privacy, fairness, and accountability contribute evidence for reliance.

## 16-responsible-ai.png

Alt text / suggested caption: Responsible AI: people govern design, deployment, monitoring, and response across the lifecycle.

## 17-sovereign-ai.png

Alt text / suggested caption: Sovereign AI: a control boundary encompasses data, models, computing, and operational skills.
